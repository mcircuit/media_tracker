# 05 — Design System

## TL;DR

Spec-driven dark-only design system. Light mode is derived from the same
seed but not shipped in v1. Every visual decision is pre-decided here —
the tutor reads, doesn't invent. Color tokens are hand-picked, not
AI-generated.

If you want to deviate (different colors, fonts, spacing), see §11 "How
to deviate" at the bottom.

## 1. Theme

**Mode:** Dark only in v1. The OS-level dark/light toggle returns dark;
the app does not respond to system theme changes in v1.

**Aesthetic:** Dark cinematic — like Plex, Infuse, or Letterboxd's dark
mode. Background near-black with a slight blue tint; primary surfaces
lifted charcoal; saturated sapphire as the single hero accent (FAB,
primary actions, "to consume" badge), warm amber for "consumed" and
rating states, cool teal for info. Source Serif 4 gives headlines an
editorial weight; Inter handles title/body/label for legibility. The
overall feel is archival and deliberate — a record of what you've
watched, not a feed.

**Color usage rules:**

- HubCards use `color/surface` (lifted from background).
- Status badges: Collection = `color/secondary` (amber), To Consume =
  `color/primary` (sapphire).
- FAB uses `color/primary-container` with `color/on-primary-container`
  text.
- AddSheet uses `color/surface` with `color/scrim` at 50% opacity.
- Error states (failed save, network) use `color/error-container` with
  `color/on-error-container` text.

**In code:**

```dart
Theme.of(context).colorScheme.primary       // color/primary
Theme.of(context).colorScheme.surface       // color/surface
// etc.
```

Never hardcode hex values. Use the colorScheme.

## 3. Typography

M3 15-role scale. Source Serif 4 on display and headline (6 roles),
Inter on title, body, and label (9 roles). Sizes, weights, line heights,
and letter spacing are M3 defaults; the serif-vs-sans split is the only
override.

| M3 role | Font | Weight | Size (sp) | Line height | Letter spacing |
|---|---|---|---|---|---|
| `displayLarge` | Source Serif 4 | 400 | 57 | 64 | -0.25 |
| `displayMedium` | Source Serif 4 | 400 | 45 | 52 | 0 |
| `displaySmall` | Source Serif 4 | 400 | 36 | 44 | 0 |
| `headlineLarge` | Source Serif 4 | 600 | 32 | 40 | 0 |
| `headlineMedium` | Source Serif 4 | 600 | 28 | 36 | 0 |
| `headlineSmall` | Source Serif 4 | 600 | 24 | 32 | 0 |
| `titleLarge` | Inter | 500 | 22 | 28 | 0 |
| `titleMedium` | Inter | 500 | 16 | 24 | 0.15 |
| `titleSmall` | Inter | 500 | 14 | 20 | 0.1 |
| `bodyLarge` | Inter | 400 | 16 | 24 | 0.5 |
| `bodyMedium` | Inter | 400 | 14 | 20 | 0.25 |
| `bodySmall` | Inter | 400 | 12 | 16 | 0.4 |
| `labelLarge` | Inter | 500 | 14 | 20 | 0.1 |
| `labelMedium` | Inter | 500 | 12 | 16 | 0.5 |
| `labelSmall` | Inter | 500 | 11 | 16 | 0.5 |

Note: no mono token in v1. If a future feature surfaces code, IDs, or
JSON, add JetBrains Mono (regular 400, weight only) via `google_fonts`.

**In code:**

```dart
Theme.of(context).textTheme.displayLarge    // serif, 57sp
Theme.of(context).textTheme.bodyLarge       // sans, 16sp
// etc.
```

## 4. Spacing scale

5 tokens on the 8px grid (4 px helper plus 2 px escape hatch for
sub-grid alignment).

| Token | Value (dp) | Use |
|---|---|---|
| `space/xxs` | 2 | Sub-grid icon-to-text gaps inside chips and dense lists. NEVER for primary spacing. |
| `space/xs` | 4 | Tight stacks, icon padding |
| `space/sm` | 8 | Inline padding within chips, default gap between sibling elements |
| `space/md` | 16 | Card inner padding, gap between cards |
| `space/lg` | 24 | Page margins, gap between major regions |

**In code:**

```dart
const SizedBox(height: 8)         // space/sm
const SizedBox(height: 16)        // space/md
// etc.
```

You can hardcode these for now (this is a small project); a
`Spacing` class with named constants is a v1.1+ cleanup if you find
yourself grepping for the same numbers.

## 5. Border radius

4 tokens, mapped to specific contexts.

| Token | Value (dp) | Context |
|---|---|---|
| `radius/sm` | 8 | `Chip`, `SnackBar`, small `FilledButton` |
| `radius/md` | 12 | `Card` (MovieCard, HubCard), `ListTile`, `TextField` |
| `radius/lg` | 20 | `AlertDialog`, `ModalBottomSheet` (AddSheet) |
| `radius/full` | 9999 | `FloatingActionButton`, `IconButton`, pill-shaped `FilledButton` |

**In code:**

```dart
borderRadius: BorderRadius.circular(12)   // radius/md
```

## 6. Motion

3 tokens, each carrying duration plus easing.

| Token | Duration | Easing | Use |
|---|---|---|---|
| `motion/fast` | 150ms | `Curves.easeInOutCubic` | Button press, ripple, snackbar enter/exit |
| `motion/default` | 250ms | `Curves.easeInOutCubic` | Page transitions, sheet open/close |
| `motion/slow` | 400ms | `Curves.easeInOutCubicEmphasized` | Hero animations, large sheet dismissal |

**Motion-reduce behavior:** when the OS-level "Remove animations"
setting is on, replace `motion/default` and `motion/slow` durations
with `Duration.zero` while keeping `motion/fast` (so button ripples
still feel responsive). Honor via
`MediaQuery.of(context).disableAnimations`.

## 7. Accessibility tokens

| Token | Value | Rule |
|---|---|---|
| `a11y/contrast/body` | 4.5:1 | WCAG 2.2 AA on body text (`bodyLarge`, `bodyMedium`, `bodySmall`) |
| `a11y/contrast/large` | 3:1 | WCAG 2.2 AA on `display*`, `headline*`, `titleLarge` |
| `a11y/touch-target/min` | 48dp | All `IconButton`, `FilledButton`, `FloatingActionButton`, `Chip.checkbox` |
| `a11y/focus-ring/width` | 2dp | Outline ring on focused interactive elements |
| `a11y/focus-ring/color` | `color/primary` | Visible focus indicator |
| `a11y/focus-ring/offset` | 2dp | Distance from element edge |
| `a11y/semantics/required` | true | Every `IconButton`, `FilledButton`, `FloatingActionButton`, `TextField` MUST have a `Semantics` label |

In Flutter, `Semantics(label: "Save movie")` wraps an interactive widget
to give TalkBack a readable name.

## 9. Layout patterns

4 patterns from `PROJECT_PLAN.md` §8.3.

1. **Hub page** (`CataloguePage`) — `Scaffold` + `body: Column` of two
   `HubCard`s stacked vertically + `floatingActionButton:
   FloatingActionButton(+)`. No `AppBar`. `space/md` between cards.
2. **List page** (`MyCollectionPage`, `ToConsumePage`) — `Scaffold` +
   optional `AppBar` (Phase 5+) + `body: ListView.builder` of
   `MovieCard`s. `space/sm` between rows.
3. **Search page** (`SearchPage`, `SearchResultsPage`) — `Scaffold` +
   `Column` with `TextField` at top, `GridView` filling remaining space,
   view-toggle row (`3x3` / `4x4` / `6x6` / list) at bottom. `space/md`
   between TextField and grid.
4. **AddSheet** (`AddSheet`, `EditSheet`) — `ModalBottomSheet` containing
   poster plus metadata header, status toggle plus rating middle
   section, action button row at bottom. `space/md` between sections.

## 10. Icons

- **Library:** Material Symbols Rounded (Google-licensed), bundled as a
  font asset at `assets/fonts/MaterialSymbolsRounded.ttf`.
- **Construction:** `IconData(fontFamily: 'MaterialSymbolsRounded',
  fontPackage: 'media_tracker')` where `media_tracker` is the pubspec
  name.
- **Size scale:**

| Token | Value (dp) | Use |
|---|---|---|
| `icon/sm` | 16 | Inline with `bodySmall`, dense list actions |
| `icon/md` | 24 | Default `IconButton`, AppBar actions, status icons |
| `icon/lg` | 32 | Hero icons (FAB content, empty-state illustration) |

- **Stroke / fill rule:** Rounded variant is the default. Use the
  **filled** variant for selected or active states (e.g., bookmark
  filled when item is on To Consume). Use the **outlined** variant for
  unselected states.
- **Color:** icons inherit `IconTheme.of(context).color` from the
  parent. Override only for status badges (Collection = `color/secondary`,
  To Consume = `color/primary`).

## 11. How to deviate

This is a personal project. You are the user. If you want a different
aesthetic — say, light mode primary, or a different seed color — you
can change tokens here and the tutor will adapt code review
accordingly.

**Allowed without changing decisions:** changing the seed color, picking
a different font pair, swapping a hex value in the color table, adding
a new size token to the spacing scale.

**NOT allowed without updating `PROJECT_PLAN.md` §16 + D-cards:**
shipping light mode as primary (contradicts D10/D19's "dark-only v1"
intent), removing components from the inventory, adding
v1-banned widgets (`NavigationBar`, `Tabs`, etc.).

If you deviate, update this file (`05-DESIGN-SYSTEM.md`) so the tutor
references your new tokens. The tutor enforces the *contract* of tokens,
not the specific values — so changing the values is fine as long as you
keep the *contract*.
